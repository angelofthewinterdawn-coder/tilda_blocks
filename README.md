# Блоки для Тильды

## Магистерская программа

Готовый код: [blocks/master-program.html](blocks/master-program.html).

1. Добавьте на страницу Тильды блок **T123 «HTML-код»**.
2. Скопируйте в него всё содержимое файла, включая стили и скрипт.
3. В `href=""` у `.kup-master__link` укажите адрес страницы программы.
4. Опубликуйте страницу и проверьте блок на опубликованной версии.

Фон — `#011961`, текст — белый, подчёркивание при наведении — `#6b1f2a`.
Шрифт — Roboto Condensed, толщина 400. Название программы расположено отдельно
от строки «Магистерская программа»; на телефонах длинное название переносится.
Наименование университета вынесено на отдельную строку, без точки в конце.

Описание плавно появляется при каждом входе в область просмотра. Инициализация
учитывает загрузку страницы Тильды. При системной настройке уменьшения движения
анимация отключается; без JavaScript описание остаётся видимым. Пока адрес ссылки
не заполнен, клик не перезагружает страницу. Google Fonts загружается извне;
если он недоступен, используется запасной шрифт.
